\# Лабораторна робота: Основні бібліотеки. Лінійні моделі навчання.



\## Опис



Лабораторна робота присвячена побудові та тренуванню моделі лінійної регресії на власному синтетичному датасеті з використанням PyTorch, а також розгортанню моделі як інтерактивного застосунку через Gradio.



\## Сценарій даних



Залежність: кількість чашок кави, випитих за робочий день (x), впливає на швидкість друку (y, символів/хвилину).



\- x — кількість чашок кави (0-6 за день)

\- y — швидкість друку (символів/хвилину)

\- w = 8 — приріст швидкості друку за кожну додаткову чашку кави

\- b = 180 — базова швидкість друку без кави

\- шум ε \~ N(0, 12) — природна варіативність (втома, настрій, складність тексту)



Формула: швидкість\_друку = w \* чашки\_кави + b + ε
